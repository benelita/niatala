🔄 ARCHITECTURE

Orange Money integrates using SAME PATTERN as Wave:

Frontend (React)
    ↓
OrangeMoneyProvider
    ├─ MANUAL mode: Local QR code + account (no backend call)
    └─ API mode: Calls backend API
        ↓
Backend (Express)
    ├─ /api/payments/create (with Orange credentials from .env)
    ├─ Calls Orange Money API (credentials never exposed to frontend)
    └─ /api/webhooks/orange (webhook confirmation)
        ↓
Orange Money API
    └─ Returns status → SUCCESS | FAILED | PENDING
